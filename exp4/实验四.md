# 实验四　基于多层感知机的 MNIST 手写数字识别


## 一、实验目的

1. 理解多层感知机（Multi-Layer Perceptron, MLP）的网络拓扑与前向传播计算过程，明确全连接层、激活函数在模型中的作用。
2. 掌握分类任务中交叉熵损失函数的定义与 PyTorch 中的实现方式，理解"网络输出 logits、损失内部做 softmax"的配合关系。
3. 独立完成反向传播与随机梯度下降（SGD）的参数更新闭环，包括梯度清零、损失反传、参数更新三个标准步骤。
4. 在 MNIST 手写数字数据集上完成 10 类分类任务，并对训练过程与分类结果进行定量分析。
5. 掌握用损失/准确率曲线判断收敛状态、用混淆矩阵定位易混类别、用样例回查分析错误成因这一套模型诊断方法。

## 三、实验原理

### 3.1 数据集

MNIST 是一个手写数字灰度图像数据集，包含 10 个类别（数字 0~9）。训练集 60 000 张、测试集 10 000 张，图像尺寸统一为 28×28 像素，像素取值 0~255。数据集中包含大量书写风格差异显著的样本，部分样本本身存在书写歧义，因此该数据集长期作为图像分类的基础基准。

### 3.2 多层感知机结构

本实验采用"一个隐藏层 + 一个输出层"的最小 MLP，结构为 784 → 128 → 10：

- **输入层**：28×28 的图像展平为 784 维向量。全连接层只能接受一维向量，因此必须先把二维图像拉平，这一步也意味着图像的二维空间结构信息被丢弃。
- **隐藏层**：128 个神经元，配合 ReLU 激活函数引入非线性。若没有激活函数，两个线性层叠加仍等价于一个线性变换，网络退化为线性分类器。
- **输出层**：10 个神经元，输出 10 个 logits，分别对应数字 0~9 的判别得分。

前向传播可写为：

$$
z_1 = xW_1^{\top} + b_1,\quad h = \mathrm{ReLU}(z_1) = \max(0, z_1)
$$
$$
z_2 = hW_2^{\top} + b_2,\quad \hat{y} = \mathrm{softmax}(z_2)
$$

参数量计算：`784×128 + 128 = 100 480`（第一层权重与偏置），`128×10 + 10 = 1 290`（第二层权重与偏置），合计 **101 770** 个可训练参数。

### 3.3 损失函数

采用多分类交叉熵损失：

$$
L = -\frac{1}{N}\sum_{i=1}^{N}\log p_{i,y_i}
$$

其中 $p_{i,y_i}$ 为样本 $i$ 在真实类别 $y_i$ 上的预测概率。PyTorch 的 `F.cross_entropy` 内部已将 `log_softmax` 与 `nll_loss` 合并，因此**输入必须是原始 logits，不能先手动 softmax**，否则相当于做了两次 softmax，会破坏梯度。

交叉熵衡量的是预测分布与真实分布（one-hot）之间的差异，其最小值随模型拟合程度提升而下降，因此损失曲线的下降趋势可直接用于判断收敛情况。

### 3.4 优化算法

采用随机梯度下降（SGD），更新规则为：

$$
\theta \leftarrow \theta - \eta \nabla_\theta L
$$

每一轮迭代的标准三步为：`optimizer.zero_grad()` 清除上一轮累积的梯度 → `loss.backward()` 反向传播计算梯度 → `optimizer.step()` 按学习率更新参数。若漏掉 `zero_grad()`，PyTorch 默认会把梯度累加，导致更新方向错误。

### 3.5 评估指标

- **准确率**：预测正确的样本数占测试集总数的比例，是本实验的主指标。
- **平均损失**：按样本总数求平均（而非按 batch 求平均），避免最后一个不满 batch 的批次带来偏差。
- **混淆矩阵**：10×10 矩阵，行表示真实类别、列表示预测类别，对角线为正确分类数，非对角元素直接给出"哪一类被误判成哪一类"及其数量。
- **分类别准确率**：混淆矩阵对角元素除以该类别真实样本数，用于定位弱势类别。

## 四、实验方案与实现

### 4.1 数据加载与预处理

使用 `torchvision.datasets.MNIST` 加载数据，并用 `transforms.ToTensor()` 完成两项变换：把 PIL 图像转为 `(1,28,28)` 的 Tensor，并把像素值从 0~255 归一化到 0~1。归一化可以避免大数值输入导致的梯度尺度失衡，使 SGD 更容易收敛。

训练集设置 `shuffle=True`，在每个 epoch 重新打乱样本顺序，避免同类样本连续出现造成参数更新方向偏置；测试集设置 `shuffle=False`，因为评估本身与顺序无关，且后续需要依靠样本索引回查原图来展示样例。

数据样例见图 1，可见 0~9 各类书写形态差异明显，同一数字的不同样本笔画粗细、倾斜角度、闭合程度都有较大变化，这正是分类难度的来源。

### 4.2 网络结构设计

网络结构见图 2。输入层接收 784 维向量，经 `nn.Linear(784,128)` 映射到 128 维隐藏表示，ReLU 激活后由 `nn.Linear(128,10)` 输出 10 个 logits。

![图2 MLP 网络结构](results/network_structure.png)

<p align="center">图 2　MLP 网络结构：784 → 128 → 10</p>

核心代码（对应 `mlp_mnist.py` 第 3 节）：

```python
class mlp(nn.Module):
    """两层全连接网络：784 -> 128 -> 10，中间用 ReLU 激活"""

    def __init__(self):
        super(mlp, self).__init__()
        self.l1 = nn.Linear(784, 128)   # 输入层 -> 隐藏层
        self.l2 = nn.Linear(128, 10)    # 隐藏层 -> 输出层（10 个类别）

    def forward(self, x):
        a1 = self.l1(x)
        x1 = F.relu(a1)                 # 隐藏层激活，引入非线性
        a2 = self.l2(x1)                # 输出 logits，交给 cross_entropy
        return a2
```

### 4.3 超参数设置

| 超参数 | 取值 | 说明 |
|---|---|---|
| batch_size | 2048 | 每批样本数，每个 epoch 约 30 次参数更新 |
| learning_rate | 0.01 | SGD 初始学习率 |
| epochs | 30 | 训练轮数 |
| 优化器 | SGD（无动量） | 最基础的梯度下降 |
| 损失函数 | CrossEntropyLoss | 内部含 softmax |
| 随机种子 | 2026 | 固定初始化与打乱顺序，保证结果可复现 |

上述取值为实验指导书原稿给定，本实验保持原设定以复现参考结果，超参数的影响在第六节单独讨论。

### 4.4 训练流程

每个 epoch 的流程为：先 `model.train()` 切换到训练模式，遍历训练集完成前向、求损失、反传、更新；再 `model.eval()` 切换到评估模式，在 `torch.no_grad()` 下遍历测试集统计 loss 与准确率，并把 `pred`、`label` 全部缓存下来，供后续绘制混淆矩阵与样例图使用。

训练循环核心代码：

```python
for epoch in range(epochs):
    model.train()
    running_loss = 0.0
    for batch_idx, (x, y) in enumerate(train_loader):
        x, y = x.view(x.shape[0], -1).to(device), y.to(device)
        optimizer.zero_grad()
        output = model(x)
        loss = F.cross_entropy(output, y)
        loss.backward()
        optimizer.step()
        running_loss += loss.item() * x.size(0)

    train_loss = running_loss / len(train_loader.dataset)

    model.eval()
    correct, total, test_loss_sum = 0, 0, 0.0
    all_preds, all_labels = [], []
    with torch.no_grad():
        for batch_idx, (x, y) in enumerate(test_loader):
            x = x.view(x.shape[0], -1).to(device)
            y = y.to(device)
            output = model(x)
            test_loss_sum += F.cross_entropy(output, y, reduction='sum').item()
            pred = output.argmax(1, keepdim=True)
            correct += pred.eq(y.view_as(pred)).sum().item()
            total += y.size(0)
```

## 六、问题分析与讨论

### 6.1 收敛速度偏慢的量化原因

本实验每个 epoch 只有约 30 次参数更新（60 000 ÷ 2048 ≈ 29.3），30 个 epoch 累计更新仅约 900 步。作为对比，若把 `batch_size` 改为 256，每个 epoch 的更新次数变为约 235 次，同样 30 个 epoch 可达到 7 050 步，是当前的 7.8 倍。

在 batch 较大时，单次梯度是对更多样本的平均，梯度噪声小、方向更稳，但也意味着**单步的有效步长相对不足**：学习率 0.01 适合小批量训练，对 2048 的大批量而言偏保守。曲线末端仍在缓慢上行，正是"步数不够"的直接体现。按线性缩放经验（批量增大 k 倍、学习率可增大 k 倍），批量从 256 放大到 2048 时学习率理论上可提高到 0.08 量级，而本实验仍取 0.01，相当于人为放慢了收敛。

### 6.2 全连接结构的固有局限

1. **丢弃空间结构**：28×28 展平为 784 维后，相邻像素的位置关系在权重中不复存在，模型无法利用"笔画是连续的局部曲线"这一先验。
2. **无参数共享**：卷积核在图像不同位置复用同一组权重，而全连接层每个输入像素都对应独立的权重，导致参数多（101 770）却对平移、缩放等变化缺乏鲁棒性。
3. **对书写变形敏感**：样本轻微平移几个像素，784 维向量中对应位置整体变化，全连接层需要重新学习，这也是本实验错分样本多为"倾斜、偏移、笔画粗细异常"的原因。
4. 单隐藏层 128 神经元对 10 类复杂字形而言表达能力有限，但单纯加宽隐藏层的收益低于引入卷积结构。

### 6.3 改进方向

基于上述分析，可行的改进措施见表 6。

表 6　改进方向与预期效果

| 改进措施 | 具体做法 | 预期效果 |
|---|---|---|
| 缩小批量、提高学习率 | `batch_size=256`，`lr=0.1` | 每 epoch 更新次数提升约 8 倍，30 epoch 内应可到 97% 以上 |
| 引入动量或自适应优化 | `optim.SGD(momentum=0.9)` 或 `optim.Adam(lr=1e-3)` | 加速收敛、缓解不同参数尺度差异 |
| 加入正则化与归一化 | 隐藏层后加 `BatchNorm1d`、`Dropout(0.2)` | 稳定训练、抑制过拟合（本实验未过拟合，收益主要在稳定性） |
| 数据增强 | `RandomRotation(10)`、`RandomAffine` 轻微平移缩放 | 提升对书写变形的鲁棒性 |
| 改用卷积网络 | LeNet-5 或两层卷积 + 池化 | 利用局部性与参数共享，MNIST 通常可达 98%~99% |
| 增加网络深度/宽度 | 隐藏层 784-256-128-10 | 提升表达能力，但需配合正则化 |

## 七、实验结论

1. 本实验在 PyTorch 中**手工搭建了一个 784-128-10 的两层全连接网络**，独立实现了前向传播、交叉熵损失、反向传播与 SGD 更新，完整跑通了训练与评估闭环。模型在 MNIST 测试集上取得 **86.20%** 的准确率，平均交叉熵损失 0.6057，错分 1 380 张。
2. 损失曲线单调下降、训练与测试 loss 差距稳定在 0.02~0.06，**未出现过拟合**；准确率曲线末端仍在上行，说明当前超参数组合下训练轮数是主要瓶颈。
3. 分类别分析显示性能不均衡：数字 0、1 的准确率超过 96%，而数字 5 仅 66.93%，主要被误判为 3 和 8；4 与 9 存在双向混淆。错误集中在结构相似的数字对上，说明模型学到了形状特征但判别力不足。
4. 通过样例回查确认，错分原因包括两类：**数据集自身的书写歧义与标注噪声**，以及**全连接结构对书写变形不鲁棒**。
5. 实验验证了 MLP 作为基础分类器的有效性，同时定量暴露了全连接结构在图像任务上的固有局限：丢弃空间结构、无参数共享、参数利用率低。这为后续引入卷积神经网络提供了明确的对照基线。

```python
# -*- coding: utf-8 -*-
"""
mlp_mnist.py

实验四：手动搭建多层感知机（MLP）完成 MNIST 手写数字识别（PyTorch 实现）

本文件是「实验四参考代码」的补全版，在原稿 1~71 行的基础上：
    1. 修复原稿中的问题：无效的 shape 语句、测试集 shuffle=True、无随机种子、超参说明
    2. 补上原稿缺失的第 72 行之后的绘图与结果输出部分（原稿 import 了 plt 却从未使用）
    3. 增加逐 epoch 的训练/测试指标记录，使 loss、accuracy 曲线有数据可画
    4. 增加混淆矩阵、错分样例可视化、每类别准确率统计，满足实验报告需要

运行方式：
    python mlp_mnist.py
输出：
    ./data      MNIST 数据集（首次运行自动下载）
    ./results/  曲线图、混淆矩阵、错分样例、模型权重、训练历史
"""

# %% ========== 1. 导入依赖与全局配置 ==========
import os
import json

import torch
import torch.nn as nn
import torch.nn.functional as F
import torch.optim as optim
import numpy as np
import matplotlib
from matplotlib.patches import FancyBboxPatch, FancyArrowPatch

# 只保存图片、不弹窗（脚本化/无界面环境下更稳）。
# 若想在 Jupyter 里交互查看，删掉下面这行 use('Agg')，把 savefig 换成 plt.show() 即可。
matplotlib.use('Agg')
import matplotlib.pyplot as plt

from torchvision import datasets, transforms

# Windows 下中文显示与负号显示
plt.rcParams['font.sans-serif'] = ['Microsoft YaHei', 'SimHei', 'DejaVu Sans']
plt.rcParams['axes.unicode_minus'] = False

# 随机种子：保证每次实验的初始化、数据打乱顺序一致，报告里的准确率才可复现
SEED = 2026
torch.manual_seed(SEED)
np.random.seed(SEED)

batch_size = 2048          # 原稿取值；想提升精度可改 256，并把 lr 调大
learning_rate = 0.01       # SGD 的初始学习率
epochs = 30                # 训练轮数
DATA_DIR = './data'        # MNIST 存放目录
RESULT_DIR = './results'   # 结果输出目录

os.makedirs(RESULT_DIR, exist_ok=True)

device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
print('PyTorch 版本:', torch.__version__)
print('当前设备:', device)


# %% ========== 2. 数据加载 ==========
train_loader = torch.utils.data.DataLoader(
    datasets.MNIST(DATA_DIR, train=True, download=True,
                   transform=transforms.Compose([
                       transforms.ToTensor(),          # PIL(28,28) -> Tensor(1,28,28)，像素归一到 [0,1]
                   ])),
    batch_size=batch_size, shuffle=True,          # 训练集必须打乱，避免同类样本扎堆影响收敛
)

# 测试集不打乱：一是评估无需打乱，二是后面画错分样例时要靠索引回查原图
test_loader = torch.utils.data.DataLoader(
    datasets.MNIST(DATA_DIR, train=False, transform=transforms.Compose([
        transforms.ToTensor(),
    ])),
    batch_size=batch_size, shuffle=False,
)

# 原稿这里的写法是 `train_loader.dataset.data.shape,`（带尾逗号的元组，不会输出任何东西），
# 改成真正的打印，用于确认数据形状为 (60000, 28, 28)
print('训练集张量形状:', tuple(train_loader.dataset.data.shape))
print('测试集张量形状:', tuple(test_loader.dataset.data.shape))


# %% ========== 3. 模型定义 ==========
class mlp(nn.Module):
    """两层全连接网络：784 -> 128 -> 10，中间用 ReLU 激活"""

    def __init__(self):
        super(mlp, self).__init__()
        self.l1 = nn.Linear(784, 128)   # 输入层 -> 隐藏层
        self.l2 = nn.Linear(128, 10)    # 隐藏层 -> 输出层（10 个类别）

    def forward(self, x):
        a1 = self.l1(x)
        x1 = F.relu(a1)                 # 隐藏层激活，引入非线性
        a2 = self.l2(x1)                # 输出 logits，交给 cross_entropy
        return a2


model = mlp().to(device)
optimizer = optim.SGD(model.parameters(), lr=learning_rate)
print(model)


# %% ========== 4. 训练 + 逐轮评估 ==========
history = {'train_loss': [], 'test_loss': [], 'test_acc': []}

for epoch in range(epochs):
    # ---- 训练阶段 ----
    model.train()
    running_loss = 0.0
    for batch_idx, (x, y) in enumerate(train_loader):
        x, y = x.view(x.shape[0], -1).to(device), y.to(device)   # (B,1,28,28) -> (B,784)
        optimizer.zero_grad()
        output = model(x)
        loss = F.cross_entropy(output, y)                        # 内部已做 softmax，故传 logits
        loss.backward()
        optimizer.step()
        # 以样本数加权累计，避免最后一个不满 batch 的批次造成偏差
        running_loss += loss.item() * x.size(0)

    train_loss = running_loss / len(train_loader.dataset)

    # ---- 测试阶段（每个 epoch 结束评估一次，供画曲线用）----
    model.eval()
    correct, total, test_loss_sum = 0, 0, 0.0
    all_preds, all_labels = [], []
    with torch.no_grad():
        for batch_idx, (x, y) in enumerate(test_loader):
            x = x.view(x.shape[0], -1).to(device)
            y = y.to(device)
            output = model(x)
            # reduction='sum' 后按样本总数相除，得到的是精确平均 loss，而不是按 batch 平均的近似值
            test_loss_sum += F.cross_entropy(output, y, reduction='sum').item()
            pred = output.argmax(1, keepdim=True)                # 取概率最大的类别
            correct += pred.eq(y.view_as(pred)).sum().item()
            total += y.size(0)
            all_preds.append(pred.view(-1).cpu())
            all_labels.append(y.cpu())

    test_loss = test_loss_sum / total
    acc = correct / total

    history['train_loss'].append(train_loss)
    history['test_loss'].append(test_loss)
    history['test_acc'].append(acc)

    print('epoch:{}, train_loss:{:.4f}, loss:{:.4f}, acc:{:.4f}'.format(
        epoch, train_loss, test_loss, acc))

print('\n' + '=' * 64)
print('训练结束：共 {} 个 epoch，最终测试集 loss = {:.4f}，accuracy = {:.2%}'.format(
    epochs, test_loss, acc))
print('=' * 64)

all_preds = torch.cat(all_preds).numpy()
all_labels = torch.cat(all_labels).numpy()


# %% ========== 5. 结果可视化（原稿缺失部分）==========

# 5.1 数据集样例（每个类别取 1 张 + 6 张随机，覆盖 0~9 全部类别）
train_images = train_loader.dataset.data.numpy()        # (60000, 28, 28)，uint8
train_targets = train_loader.dataset.targets.numpy()

per_class_idx = [np.where(train_targets == d)[0][0] for d in range(10)]
random_idx = np.random.choice(len(train_images), 6, replace=False)
sample_idx = np.concatenate([np.array(per_class_idx), random_idx])

fig, axes = plt.subplots(4, 4, figsize=(7, 7.6))
for k, ax in enumerate(axes.flat):
    idx = sample_idx[k]
    ax.imshow(train_images[idx], cmap='gray')
    ax.set_title('标签:{}'.format(train_targets[idx]), fontsize=10)
    ax.axis('off')
fig.suptitle('MNIST 训练集样例（28×28 灰度图，0~9 各一例 + 随机 6 例）', fontsize=11)
fig.tight_layout()
fig.savefig(os.path.join(RESULT_DIR, 'dataset_samples.png'), dpi=200)
plt.close(fig)
print('已保存:', os.path.join(RESULT_DIR, 'dataset_samples.png'))

# 5.2 网络结构示意图（矩形高度按神经元数量示意）
def draw_layer(ax, x, w, h, label, facecolor):
    y0 = (1.0 - h) / 2.0
    box = FancyBboxPatch((x, y0), w, h, boxstyle='round,pad=0.015',
                         linewidth=1.4, edgecolor='#333333', facecolor=facecolor)
    ax.add_patch(box)
    ax.text(x + w / 2.0, 0.5, label, ha='center', va='center', fontsize=11.5)


def draw_arrow(ax, x1, x2, text):
    arr = FancyArrowPatch((x1, 0.52), (x2, 0.52), arrowstyle='-|>', mutation_scale=16,
                          linewidth=1.4, color='#666666')
    ax.add_patch(arr)
    ax.text((x1 + x2) / 2.0, 0.38, text, ha='center', va='top',
            fontsize=9, color='#333333', linespacing=1.3)


fig, ax = plt.subplots(figsize=(10, 4.0))
ax.set_xlim(0, 1)
ax.set_ylim(0, 1)
ax.axis('off')

draw_layer(ax, 0.02, 0.22, 0.50, '输入层\n784', '#dbe7f3')
draw_layer(ax, 0.38, 0.20, 0.30, '隐藏层\n128\nReLU', '#e8f0db')
draw_layer(ax, 0.72, 0.22, 0.14, '输出层\n10', '#f3e6db')

draw_arrow(ax, 0.24, 0.38, 'W1  784×128\n+128 偏置')
draw_arrow(ax, 0.58, 0.72, 'W2  128×10\n+10 偏置')

ax.text(0.5, 0.13, '28×28 图像拉平为 784 维向量；输出 10 个 logits 对应数字 0~9',
        ha='center', va='center', fontsize=10, color='#333333')
ax.text(0.5, 0.05, '总参数量 = (784×128 + 128) + (128×10 + 10) = 101,770',
        ha='center', va='center', fontsize=10.5, color='#111111')
ax.set_title('MLP 网络结构：784 → 128 → 10', fontsize=13, pad=14)

fig.tight_layout()
fig.savefig(os.path.join(RESULT_DIR, 'network_structure.png'), dpi=200)
plt.close(fig)
print('已保存:', os.path.join(RESULT_DIR, 'network_structure.png'))

# 5.3 训练/测试 loss 曲线 + 测试 accuracy 曲线
fig, axes = plt.subplots(1, 2, figsize=(13, 4.6))
ep = np.arange(1, len(history['train_loss']) + 1)

axes[0].plot(ep, history['train_loss'], 'o-', lw=1.8, label='训练集 loss')
axes[0].plot(ep, history['test_loss'], 's-', lw=1.8, label='测试集 loss')
axes[0].set_xlabel('epoch')
axes[0].set_ylabel('loss')
axes[0].set_title('交叉熵损失曲线')
axes[0].grid(alpha=0.3)
axes[0].legend()

axes[1].plot(ep, np.array(history['test_acc']) * 100, 'o-', color='tab:green', lw=1.8)
axes[1].set_xlabel('epoch')
axes[1].set_ylabel('accuracy (%)')
axes[1].set_title('测试集准确率曲线')
axes[1].grid(alpha=0.3)
axes[1].axhline(history['test_acc'][-1] * 100, ls='--', lw=1, color='gray',
                label='最终准确率 {:.2f}%'.format(history['test_acc'][-1] * 100))
axes[1].legend()

fig.tight_layout()
fig.savefig(os.path.join(RESULT_DIR, 'loss_acc_curve.png'), dpi=200)
plt.close(fig)
print('已保存:', os.path.join(RESULT_DIR, 'loss_acc_curve.png'))

# 5.4 混淆矩阵（行 = 真实类别，列 = 预测类别）
num_classes = 10
cm = np.zeros((num_classes, num_classes), dtype=np.int64)
np.add.at(cm, (all_labels, all_preds), 1)

fig, ax = plt.subplots(figsize=(8.2, 7))
im = ax.imshow(cm, cmap='Blues')
ax.set_xlabel('预测类别')
ax.set_ylabel('真实类别')
ax.set_xticks(range(num_classes))
ax.set_yticks(range(num_classes))
ax.set_title('MNIST 测试集混淆矩阵（样本数）')
# 在每格写上数值，深色格子用白字
thresh = cm.max() / 2.0
for i in range(num_classes):
    for j in range(num_classes):
        ax.text(j, i, cm[i, j], ha='center', va='center', fontsize=9,
                color='white' if cm[i, j] > thresh else 'black')
fig.colorbar(im, ax=ax, fraction=0.045)
fig.tight_layout()
fig.savefig(os.path.join(RESULT_DIR, 'confusion_matrix.png'), dpi=200)
plt.close(fig)
print('已保存:', os.path.join(RESULT_DIR, 'confusion_matrix.png'))

# 5.5 每类别识别准确率（对角元素 / 该类别真实样本数）
per_class_acc = cm.diagonal() / cm.sum(axis=1)
print('\n每类别准确率:')
for d in range(num_classes):
    n = int(cm[d].sum())
    print('  数字 {:<2d}: {:.2%}   (样本数 {})'.format(d, per_class_acc[d], n))

# 5.6 正确预测样例（与错分样例对照）
test_images = test_loader.dataset.data.numpy()          # (10000, 28, 28)，uint8
correct_idx = np.where(all_preds == all_labels)[0]

if len(correct_idx) > 0:
    # 按类别各取 1 张，再补 6 张随机样本，避免出现"全是同一数字"的样例图
    per_class_correct = []
    for d in range(num_classes):
        d_idx = correct_idx[all_labels[correct_idx] == d]
        if len(d_idx) > 0:
            per_class_correct.append(d_idx[0])
    random_correct = np.random.choice(correct_idx, 6, replace=False)
    sample_idx = np.concatenate([np.array(per_class_correct, dtype=np.int64), random_correct])

    n_show = min(16, len(sample_idx))
    fig, axes = plt.subplots(4, 4, figsize=(8.5, 8.8))
    for k, ax in enumerate(axes.flat):
        if k < n_show:
            idx = sample_idx[k]
            ax.imshow(test_images[idx], cmap='gray')
            ax.set_title('真值:{} 预测:{}'.format(all_labels[idx], all_preds[idx]),
                         fontsize=10, color='#1a7f37')
        ax.axis('off')
    fig.suptitle('预测正确样例（0~9 各一例 + 随机 6 例）', fontsize=12)
    fig.tight_layout()
    fig.savefig(os.path.join(RESULT_DIR, 'correct_samples.png'), dpi=200)
    plt.close(fig)
    print('已保存:', os.path.join(RESULT_DIR, 'correct_samples.png'))

# 5.7 错分样例可视化
wrong_idx = np.where(all_preds != all_labels)[0]
print('\n错分样本总数: {} / {}'.format(len(wrong_idx), len(all_labels)))

if len(wrong_idx) > 0:
    n_show = min(16, len(wrong_idx))
    fig, axes = plt.subplots(4, 4, figsize=(8.5, 8.8))
    for k, ax in enumerate(axes.flat):
        if k < n_show:
            idx = wrong_idx[k]
            ax.imshow(test_images[idx], cmap='gray')
            ax.set_title('真值:{} 预测:{}'.format(all_labels[idx], all_preds[idx]), fontsize=10)
        ax.axis('off')
    fig.suptitle('前 {} 个错分样本'.format(n_show), fontsize=13)
    fig.tight_layout()
    fig.savefig(os.path.join(RESULT_DIR, 'misclassified.png'), dpi=200)
    plt.close(fig)
    print('已保存:', os.path.join(RESULT_DIR, 'misclassified.png'))


# %% ========== 6. 保存模型与训练历史 ==========
torch.save(model.state_dict(), os.path.join(RESULT_DIR, 'mlp_mnist.pt'))
with open(os.path.join(RESULT_DIR, 'history.json'), 'w', encoding='utf-8') as f:
    json.dump(history, f, ensure_ascii=False, indent=2)

print('\n产物清单:')
for name in ['dataset_samples.png', 'network_structure.png', 'loss_acc_curve.png',
             'confusion_matrix.png', 'correct_samples.png', 'misclassified.png',
             'mlp_mnist.pt', 'history.json']:
    path = os.path.join(RESULT_DIR, name)
    print('  {}  {}'.format('√' if os.path.exists(path) else '×', path))
```
